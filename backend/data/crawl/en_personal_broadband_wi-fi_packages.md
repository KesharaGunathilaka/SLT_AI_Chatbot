###  [](javascript:void\(0\))Wi-Fi Packages
#### Postpaid Wi-Fi Access
All existing broadband users are eligible to use their existing credentials at any SLT Wi-Fi hotspot. Using SLT Wi-Fi hotspots, now you can get connected to the largest broadband network and experience the next evolution in wireless broadband connectivity through any Wi-Fi enabled device.
#### How to use
  * Enter your broadband account credentials on default landing page. eg: Username :**PC222222** Password: **XXXXXXX**
  * Usage will be added to your broadband account and can be accessed via MySLT App/Portal.
